# [Half Diamond Star Pattern](https://www.geeksforgeeks.org/problems/triangle-pattern-1661718013/1)
## Easy
Given an integer n, print the Half Diamond Star Pattern using * characters as shown in the examples.
Examples:
Input: 5
Output:
* 
* * 
* * * 
* * * * 
* * * * *
* * * *
* * *
* *
*
Input: 3
Output:
* 
* * 
* * * 
* *
*
Constraints:1 ≤ n ≤ 100
